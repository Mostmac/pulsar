# HackAlice patch kit / набор патчей Pulsar

Отдельная ветка-архив личных доработок. Оригинальные ветки `main` и `custom` не изменяются. Ни одна команда этого набора не подключается к колонке или Home Assistant, не меняет их настройки и не даёт разрешения на автоматическую установку.

## Быстрый старт

Один раз скачать набор на компьютер/машину сборки:

```sh
git clone --single-branch --branch hackalice-kit https://github.com/Mostmac/pulsar.git pulsar-kit
```

Одна команда для восстановления исходников прежней кастомной версии в **новый** каталог:

```sh
sh pulsar-kit/hackalice-kit/prepare.sh legacy pulsar-legacy
```

Пробный перенос **всего** старого набора на выбранный оригинальный релиз:

```sh
sh pulsar-kit/hackalice-kit/prepare.sh legacy pulsar-port-v070 v0.7.0
```

Это проверяет и применяет исходный diff, а не устанавливает прошивку. Если патчи конфликтуют, процесс остановится, не затронув старые исходники. Даже успешное применение diff не доказывает правильность работы новой версии. Такой перенос требует проверки исходников, сборки и испытаний на станции.

Для воспроизведения отдельного эксперимента:

```sh
sh pulsar-kit/hackalice-kit/prepare.sh wake-corr-lab pulsar-wake-lab
```

Патч-скрипт создаёт независимый Git-репозиторий, проверяет закреплённые ревизии и SHA-256 диагностических патчей, применяет их через `git apply --check --index` и `git apply --index`. Только после завершения всех проверок записывает `.git/hackalice-kit-ready`. При ошибке сохраняет отдельный каталог для анализа; повторно использовать существующий каталог нельзя. Рабочая станция не изменяется.

## Профили

| Профиль | Основа | Что входит | Статус |
| --- | --- | --- | --- |
| legacy | Mostmac/pulsar `6385a0b1b0f5c61277cd181c14f06d803155cc33` | Все изменения, закоммиченные в прежней ветке custom относительно `1a45067e30f9f9081252a65f87242e2a5659d25a` | Источник прежней версии; точное совпадение с ранее развернутым бинарником при наличии незакоммиченных правок не гарантируется |
| legacy + upstream-ref | Явно заданный оригинальный релиз/коммит | Суммарный diff прежней custom | Непроверенный перенос |
| wake-corr-lab | Morvex885/pulsar `37e2fe1c7e3438f05ebc7f8f1fc53030feb675e3` | Wake levels, диагностика корреляции R8/R9 и VQE, отключение повторного звука при автоматическом follow-up | Только диагностика, не готовое эхоподавление |

Диагностические патчи добавлены для воспроизводимости эксперимента. Новый фильтр эхоподавления ещё не реализован. Патчи не записывают аудиофайлы и не добавляют ключи или настройки конкретной системы.

## Сборка

Использовать штатные инструкции Pulsar и подходящий Linux-стенд. Например, в подготовленной среде со штатными Rust, Zig и cargo-zigbuild:

```sh
cd pulsar-wake-lab/satellite
cargo fmt --all
cargo test -p pulsar-audio --lib --locked wake_corr::tests
make ARCH=armhf -j1 VERSION=v0.6.2-7-g37e2fe1-wake-corr binary
```

Проверять архитектуру, контрольную сумму и версию. Диагностику запускать отдельно с `PULSAR_WAKE_LEVELS=1` и `PULSAR_WAKE_CORR=1`. Не использовать автоматическую установку на рабочую колонку.

## Дальнейшее сопровождение

После испытаний выделять отдельно проверенные функциональные патчи (не переносить лабораторную диагностику в рабочую версию). Для каждого фиксировать upstream-ревизию, зависимости, тесты и статус совместимости. Выпуск следующей версии должен проверять патчи, сборку и совместимость скриптов управления, отдельно сохранять настройки, маркеры local-only и рабочий бинарник, а также иметь проверенный откат. Установщик в одну команду добавлять только после проверки на реальном устройстве: новые версии Pulsar могут требовать обновления супервизора, а не одного бинарника.

Конфигурации конкретной станции, SSH-ключи, API keys, Wi-Fi, голосовые отпечатки, записи речи и личные диагностические логи **никогда не коммитятся**.
